Deliberately break and restore the observation contract

The goal-fault run replaces both goal encodings with “the goal is at the current cube position.” The simulator's actual goal, reward and scoring stay intact. The restored run disables that fault on the same clone without retraining. Every restored episode must exactly reproduce the clean reference, so this separates an input bug from a change to physical dynamics.
